# 云服务器部署步骤

> 目标：Debian 系云服务器（2C2G），有域名 + TLS。部署 element-skin demo 站 + Webhook 接收端。

## 快速开始

**手动部署**：请直接参考 [手动部署清单.md](手动部署清单.md)，逐步执行并验证。

**一键脚本**：若已同步代码到服务器，可运行 `deploy/setup.sh`（需先编辑 `.env` 与 `config.json`）。

## 架构（共用域名场景）

```
┌────────────────────────── 云服务器 ──────────────────────────┐
│  Nginx (443, TLS)  union-test.gpa.ac.cn                     │
│   ├─ /wh/*          → FastAPI 接收端 (127.0.0.1:8080)        │
│   ├─ /skinapi/*     → element-skin backend:8000              │
│   └─ /*             → element-skin 前端                      │
│  Docker Compose: db + redis + backend + webhook-worker       │
│  Systemd: element-skin-receiver                              │
└─────────────────────────────────────────────────────────────┘
```

## 前置条件

- 云服务器：Debian 系（Ubuntu/Debian），2C2G，公网 IP；
- 域名：`union-test.gpa.ac.cn`（element-skin 与接收端共用，接收端挂 `/wh/` 前缀）；
- SSH 可登录（root 或 sudo 用户）；
- 已安装 Docker + Docker Compose。
